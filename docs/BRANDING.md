# GoreeCloud Remote MCP Branding

## Product Name

**GoreeCloud Remote MCP**

## Naming

- Repository: `GoreeCloud/remote-mcp`
- MCP tool namespace: `goreecloud.remote.*`
- Service labels should use “GoreeCloud Remote MCP”.
- Avoid presenting the Development prototype as a finished consumer product or production service.

## Voice

Product and operational copy should be direct, technical, privacy-aware, and evidence-based. Security status must reflect real controls rather than decorative trust language.

## Current Visual Surface

The Development dashboard is an operational status surface, not a finalized Glaze consumer interface. No application-specific Glaze acceptance or production visual qualification is established.
